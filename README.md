# Torre al Infinito

Juego 3D para navegador hecho con [Three.js](https://threejs.org/). Eres un obrero que dirige una grúa para construir la torre más alta jamás hecha: desde la obra en la ciudad, pasando por las nubes y el espacio, hasta la Vía Láctea.

## Cómo jugar

Abre `index.html` en el navegador (ordenador o móvil).

1. **Introducción**: llega a la obra, habla con Paco (el encargado) y camina hasta la plataforma elevadora.
   - Ordenador: WASD / flechas, o clic en el suelo.
   - Móvil: arrastra el dedo (joystick).
2. **Construcción**: apunta con el ratón o el dedo donde quieres la planta y suelta (clic / levantar el dedo) para dejarla caer.
   - Lo que sobresale se rompe y la siguiente planta es más pequeña.
   - 3 perfectos seguidos hacen crecer la planta.
   - Desde las nubes sopla viento cada vez más fuerte.

## Opciones

- Calidad gráfica (Baja / Media / Alta)
- Sonido y volumen
- Ayuda de puntería
- Modo dios (todo cae perfecto; no cuenta para el récord)
- Saltar la introducción
